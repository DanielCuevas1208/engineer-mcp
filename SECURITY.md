# Security

## Reporting a vulnerability

Report security issues privately.
Open a private advisory on GitHub.
Do not share the flaw in a public issue.

Include the affected version.
Include the steps to reproduce.
Include any relevant logs.

The maintainers will confirm the report.
They will work on a fix.
They will credit you for the report.

## Dependency policy

The project uses a locked dependency tree.
`package-lock.json` pins every package version.
Review dependency updates in the change log.
